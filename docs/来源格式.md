# 测序样本资料接入来源格式

支持 SAM 1.6 文本，不需要 BAM/CRAM。保存 HD/SQ/RG 声明，字段含 FLAG 位、1-based POS、CIGAR、RNEXT/PNEXT 和 optional tags (A/i/f/Z/H/B)。未比对位置0与缺值*不同；CIGAR 的 M/D/N/=/X 消耗参考，M/I/S/=/X 消耗读段，H/P不消耗二者。记录身份至少含来源文件与行偏移，不能用 QNAME 唯一化；同名不同读组隔离。主/次/补充标志独立保存。referenceSpan 使用0-based半开区间并保留原坐标，未闭合的 mate 是 unresolved 而非 missing-read。

文件允许按坐标而非读名排序，解析不依赖排序；一次结构化收件可通过 sources 声明多个来源文件，配对端可以位于不同交付文件中，关系索引跨文件建立。范围内只接收来源已给出的比对记录：主比对、次级比对（0x100）和补充片段（0x800）逐条保存，不按读段名称合并；未比对读段（FLAG 0x4）保留位置 0、CIGAR/SEQ 缺值等原始约定；来源未提供的对端在 relationship 中标记 unresolved，不补造记录、不重新比对、不判断变异。

头部仅承诺解析 @HD、@SQ、@RG；其他头部记录（如 @PG、@CO）原文保留在 coverage 的 otherHeaderRecords，并以 unsupported-header issue 明确标注，不假装完整解析。可选标签只承诺 A/i/f/Z/H/B 六类，其余或值非法的标签保留原文并定位问题。无法按 UTF-8 解码、必填字段缺失、FLAG/POS 等基础字段非法的行产生 fatal issue；当没有任何可解释记录或存在 fatal 问题时收件状态为 rejected，可解释但存在问题或未闭合关系时为 partial，全部闭合且无问题才为 complete。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://samtools.github.io/hts-specs/SAMv1.pdf。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
